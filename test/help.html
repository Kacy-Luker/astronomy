How to add a session

  1. Scan the spreads you wrote on, including the one the session started on, into one PDF (a JPEG works too).
  2. Upload it to astronomy-scans (Add file → Upload files) in the notebook's folder, named for the date: astronomy-001/2026-10-20.pdf. Add a 24-hour time when you upload more than once a day: 2026-10-20-1350.pdf.
  3. Import: open Actions → Import, tap Run workflow, pick the notebook, and run it. Leave the scan empty to use the newest file in the notebook's folder.
  4. Check the pull request it opens: compare the preview link with your pages, and fix any misread field in the pull request itself (Files changed → the session's file → ⋯ → Edit file), so the fix goes in with the import.
  5. Merge it. Merge each import before running the next.

Other imports

  • New notebook: upload into a new folder (e.g. astronomy-002/), starting with the closed notebook, then pick new-notebook and its notebook type. The folder name becomes its id.
  • Re-read pages: scan those spreads, pick the notebook and tick reread. What was recorded for them is replaced.
  • Front cover: scan the closed notebook on its own and pick Front cover as the category.
  • Page numbers missed: if the scanner cut off the printed numbers, put the first session page's number in start page.
  • Wrong category: pick the right one in category and every non-blank page in the scan goes there.

Finishing a notebook

  1. Run Actions → Complete notebook with no scan. Its pull request lists what to rescan: the front cover, table of contents and index, plus every blank page to check.
  2. Scan those spreads in any order into one file (the closed notebook can go in it too), upload it, and run Complete notebook again with that file.

Removing a notebook

Actions → Remove notebook: type the notebook's id in confirm. Its pull request deletes the notebook, its pages and its sessions from the site; the scans in astronomy-scans are kept.

Fixing things later

  • Once merged, turn on Edit links in the admin bar at the top of any page: they open sessions, observations, notebooks and your mappings (from object pages) in GitHub's editor. Write N/A where a field doesn't apply; a blank field is a to-do.
  • In the installed app, Admin mode: on turns this bar off; Admin mode: off at the bottom of any page turns it back on. Test data switches between your log and the test site.
  • Everything else is in the README.
